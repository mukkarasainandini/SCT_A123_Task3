I’m excited to share my General Knowledge Quiz App built using HTML, CSS, and JavaScript 
🧠 About the quiz game
This interactive quiz application allows users to test their general knowledge through multiple-choice questions in a simple and user-friendly interface.
> *** Key Features**

*Multiple-choice GK questions
* Instant feedback on answers
*Score calculation at the end of the quiz
*Dynamic functionality using JavaScript
HTML – Structure of the quiz
CSS – Styling and responsive layout
JavaScript – Quiz logic, scoring, and interactivity
🎯 Purpose
This project helped me strengthen my understanding of DOM manipulation, event handling, and basic logic building in JavaScript.
